# KiCad Import Assistant

KiCad Import Assistant is a standalone Python desktop utility for importing vendor-provided KiCad footprints, symbols, and 3D models into a local KiCad library structure.

The project is designed around a cautious import workflow: preview discovered files, review planned actions, confirm selected writes, create backups where needed, and avoid unsafe overwrites.

## Project Status

KiCad Import Assistant is an independent open-source tooling project maintained by Phoenixjack.

The application is intended for local desktop use with KiCad library files. It is not affiliated with KiCad, Texas Instruments, or any other component manufacturer.

## Manufacturer API Usage

Planned manufacturer API support is intended to retrieve public component metadata, datasheets, packaging details, and related part information to improve KiCad import planning.

API credentials, when used, are stored locally by the user. This project site does not collect API keys, user credentials, KiCad library contents, or imported component data.
