# Privacy and API Data Use

KiCad Import Assistant is a local desktop utility. The application is designed to run on the user's machine and work with local KiCad library files.

## Data Collection

This project site does not collect personal information, API credentials, KiCad library files, imported component files, or component metadata.

## API Credentials

Manufacturer and distributor API credentials, when configured, are intended to remain on the user's local machine. Credentials should not be committed to the public repository.

## API Requests

Manufacturer API integrations are intended to request public component information such as manufacturer part numbers, datasheets, descriptions, package details, and ordering metadata. This information may be used locally to improve import previews and naming suggestions.
